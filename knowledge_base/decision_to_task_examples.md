# Decision → Task Examples

Worked examples showing how a raw meeting statement becomes a correctly formatted JIRA task. Use the same style for new tasks — title with a domain prefix, a priority, and tags drawn only from the approved tag list.

- **"Mobile app is slow"** → `[Mobile] Investigate application performance regression` | Priority: High | Tags: team-mobile, performance
- **"API v2 documentation is missing, will be completed in 2 weeks"** → `[Backend] Complete API v2 documentation` | Priority: Low | Tags: team-backend, documentation
- **"Recommendation model will be tested in staging before the next release"** → `[AI] Run recommendation model staging evaluation` | Priority: Medium | Tags: team-ai, ml-model
- **"There is a delay in the data pipeline, needs investigation"** → `[Data] Investigate data pipeline delay` | Priority: High | Tags: team-data, data-pipeline
- **"We need a hotfix for the login crash, DevOps should know today"** → `[Backend] Hotfix login crash on authentication` | Priority: High | Tags: team-backend, hotfix
- **"New intern starts Monday, HR needs the onboarding doc ready"** → `[HR] Prepare onboarding checklist for new intern` | Priority: Medium | Tags: team-hr, onboarding
- **"The checkout query is slow, might be technical debt from the old schema"** → `[Backend] Investigate checkout query performance` | Priority: Low | Tags: team-backend, technical-debt, performance
